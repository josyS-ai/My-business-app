☁️ Synchronisation entre appareils

Contrairement à vos autres apps, il n'y a pas de code à saisir ici : la connexion à votre base de données est déjà intégrée directement dans ce fichier ministere.html. La synchronisation est donc automatique et immédiate entre tous les appareils qui ouvrent ce même fichier (les 3 comptes Adultes / Jeunes / Enfants y sont déjà inclus).

Pour ajouter un nouvel appareil : envoyez-vous simplement ce fichier ministere.html (par WhatsApp, email, Drive...) et ouvrez-le sur l'autre appareil — les données seront les mêmes des deux côtés en temps réel.

🔒 Code PIN

Désactivé

Si activé, un code à 4 chiffres sera demandé à chaque ouverture de l'app sur cet appareil.

⬇️ Exporter mes données (sauvegarde complète)

Télécharge un fichier contenant tout : disciples, séances, présences, finances, prières, témoignages, notes, évaluations — pour les 3 comptes. Gardez-le en lieu sûr (Drive, email...), faites-le régulièrement.

⬆️ Importer des données

Restaure une sauvegarde précédemment exportée, ou transfère vos données vers un autre appareil.
Attention : cela remplace entièrement les données actuelles (des 3 comptes). Exportez d'abord si vous voulez garder une copie de secours.

🗑️ Réinitialiser toutes les données

Action irréversible.

Supprime définitivement toutes les données du compte actuellement sélectionné () : disciples, séances, finances, prières, témoignages, notes, évaluations.

Exportez d'abord une sauvegarde ci-dessus si vous voulez pouvoir revenir en arrière.
